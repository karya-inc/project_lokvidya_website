# 🪷 Project Lokvidya

**A living archive of people's knowledge**

Lokvidya is a digital data archive preserving indigenous wisdom from communities across India. The platform documents folksongs, agricultural practices, forest knowledge, food traditions, and cultural heritage in 15+ native languages.

## 🌟 Features

- **Dual-Axis Filtering**: Explore data by language OR by category
- **Interactive India Map**: Click on states to filter by regional languages
- **Animated Statistics**: Real-time counters and visualizations
- **Responsive Design**: Works seamlessly on all devices
- **Category-Based Organization**: 
  - 🎵 Folksongs
  - 🌾 Agriculture
  - 🌲 Forest
  - 🍲 Food/Nutrition
  - 🏛️ Culture/Traditions
  - 📁 Other

## 🗣️ Supported Languages

| Region | Languages |
|--------|-----------|
| **Jharkhand** | Mundari, Ho, Santhali, Khortha, Sadri |
| **Assam** | Assamese, Bodo, Deuri |
| **Arunachal Pradesh** | Wangcho, Kaman Mishmi |
| **Other NE States** | Nagamese, Khasi, Meitei |
| **Pan-India** | Hindi, English |

## 🚀 Getting Started

Simply open `index.html` in your browser. No build process required!

```bash
# Clone the repository
git clone https://github.com/your-org/lokvidya.git

# Open in browser
open index.html
# OR
start index.html  # Windows
```

## 🎨 Design System

The design uses a Karya.in-inspired color palette:

| Color | Hex | Usage |
|-------|-----|-------|
| Saffron | `#FF6B35` | Primary accent, CTAs |
| Terracotta | `#D64933` | Secondary accent |
| Deep Teal | `#004E64` | Headers, primary text |
| Forest Green | `#2A7F62` | Success states |
| Warm Cream | `#FFF8F0` | Primary background |
| Gold Ochre | `#E8A838` | Highlights |

**Typography**:
- **Playfair Display** - Display/Headers (cultural gravitas)
- **Work Sans** - Body text (clean, readable)
- **Outfit** - Numbers/accents (geometric)
